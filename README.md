# 知物 · 商品策略工作台

将「电商商品策略师」的分析框架做成可交互的中文网页应用。提供产品图片和卖点资料，生成五项策略分析，并保留资料依据和待验证项。

## 功能

1. **产品卖点拆解**：功能、效果、情绪、信任、差异化五维度，支持筛选，展示依据和可拍画面。
2. **人群分析**：主攻、次攻、补充人群，展示购买触发、需求、顾虑及定性优先级。
3. **场景分析**：谁在什么触发条件下做什么、遇到什么问题、商品如何参与。
4. **买点翻译**：原始卖点与用户购买理由并排对照，含可用表达及证据。
5. **创意测试矩阵**：纯产品、人物引流、剧情带货，展开查看前三秒、中段、结尾及素材要求。

支持拖放上传最多 4 张 JPG/PNG/WebP 图片（每张 ≤ 8MB）、内容平台选择、示例报告、本机报告保存、复制和完整 Markdown 导出；适配手机。

## 启动

需要 **Node.js 24+** 与 npm。在当前任务已有的 `/workspace/git` 检出目录开发，不需另外创建 worktree。

```bash
cd /workspace/git
npm ci
npm run dev
```

Vite 前端默认端口 **5173**，将 `/api` 转发至 **3001** 的 Node 服务。当前环境若限制启动本地服务或代理网络，需要使用平台提供的对应执行权限。Node 使用 `--use-env-proxy` 保留环境注入的 HTTP/HTTPS 代理，不关闭 TLS 校验。

未配置模型也能查看完整的**合成示例报告**。真实商品分析需要连接支持视觉输入、Chat Completions 和 JSON 输出的模型；不会使用示例内容冒充真实分析。

### 连接真实 AI

两种方式任选其一：

- 在页面的**模型设置**输入 API 地址、模型名称和自己的 API Key。Key 仅保留在本次页面内存中，刷新即清除；浏览器只保存地址和模型名称。
- 在服务器配置环境变量。可参考 `.env.example`，将配置放在被 Git 忽略的 `.env` 中：

```dotenv
STRATEGY_API_KEY=在本地配置真实密钥
STRATEGY_BASE_URL=https://api.openai.com/v1
STRATEGY_MODEL=gpt-4o-mini
PORT=3001
```

API 地址应以 `/v1` 等接口根路径结束，应用会追加 `/chat/completions`。公网地址要求 HTTPS；本机兼容服务允许 HTTP。自定义 API 地址需提供对应个人 Key，不会向自定义地址转发服务器配置的 Key。模型请求超时为 120 秒，取消分析会中止上游请求。

如使用受限网络，需在云环境设置允许实际模型服务域名（例如 `api.openai.com`）。当前环境尚未配置真实模型密钥，真实服务调用需部署者完成此项配置。

### 生产运行

```bash
npm run build
npm start
```

同一个 Node 服务在 **3001** 端口提供构建产物与 API。公开部署时请配置 HTTPS、登录认证、请求限流和费用控制；当前版本面向个人或受信任团队工作空间，未提供多用户隔离。

**公网发布**：本机端口不等于公网网址。已提供 Render Blueprint 与 Dockerfile，具体步骤见 [DEPLOY.md](DEPLOY.md)；实际发布需要连接托管账号或服务器入口。

## 验证

```bash
npm test
npm run build
python tests/browser-smoke.py
```

`npm test` 使用 Node 内置测试运行器执行 HTTP 集成测试，包括真实请求格式、多模态载荷、模型结构校验、服务错误、密钥边界和取消请求。模型调用使用注入的模拟 fetch，不产生费用。

浏览器测试需要 Python Playwright、Chromium，以及运行中的 `npm run dev`；默认通过 `/usr/bin/chromium` 检查五模块交互、上传、导出、保存、错误处理、模拟 AI 分析和移动端。`BASE_URL` 可覆盖测试地址。真实提供方的端到端调用需要有效密钥，未以模拟测试结果冒充已验证。

## 资料与隐私

- 产品资料和图片只在点击生成时发送到配置的模型提供方；应用不主动将其存入服务器文件或数据库。提供方的数据保留依其政策。
- 用户点击「保存报告」才把分析文字保存在当前浏览器，最多 20 份；不包含上传图片或 API Key。可在「我的报告」删除，或导出 Markdown。
- 示例商品、规格、价格均为合成演示资料，示意插画不是实拍或性能证明。
- 资料给出、策略假设、待验证分别标注；高／中／低是策略判断，不是市场统计，不承诺销量或转化结果。
